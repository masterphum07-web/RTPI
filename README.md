# RTPI — เว็บไซต์รวมตารางสอบ/ตารางสอน สาขาวิชารังสีเทคนิค วทก.

เว็บสำหรับนักศึกษาสาขาวิชารังสีเทคนิค วิทยาลัยพระบรมราชชนก (วทก.)
ใช้ค้นหา **ตารางสอบ ตารางสอน และติดตามกิจกรรม/ข่าวสารของสาขา** — ข้อมูลทั้งหมดอยู่บน Google Sheets ของสาขา แก้ที่ชีตแล้วเว็บอัปเดตเองภายใน 1 นาที

## โครงสร้างโปรเจค

```
RTPI/
├── index.html          หน้าแรก (สถิติ, สอบใกล้ถึง, ประกาศล่าสุด)
├── exams.html          ตารางสอบ + แท็บรูปประกาศตารางสอบจากสาขา (ซูมได้)
├── schedule.html       ตารางสอน (มุมมองรายวัน / ตารางรายสัปดาห์)
├── activities.html     ฟีดกิจกรรม/ประกาศ/ทุน/ฝึกงาน
├── search.html         ค้นหารวมทุกอย่างจากที่เดียว
├── css/style.css       ธีมทางการ (น้ำเงิน–ทอง) + โหมดมืด
├── js/config.js        ⚙️ ตั้งค่า SHEET_ID / SHEET_URL
├── js/data.js          ดึงข้อมูลจากชีต (gviz) หรือ Apps Script + auto-refresh
├── js/ui.js            Header/Footer/สถานะ/โหมดมืด/Lightbox
├── apps-script/Code.gs สคริปต์ติดตั้งชีต + ให้บริการ JSON (ทางเลือก)
└── manifest.webmanifest ทำให้ติดตั้งเป็นแอปบนมือถือได้ (PWA)
```

## การเชื่อมต่อข้อมูล

### โหมด A — อ่านจากชีตตรง ๆ (ใช้งานอยู่)
ใส่ `SHEET_ID` ใน `js/config.js` โดยชีตต้องแชร์เป็น **"ทุกคนที่มีลิงก์ — ผู้ดู"**
เว็บจะอ่านแท็บ: `Schedule`, `Exams`, `Posts`, `ExamImages`, `Config` โดยตรง ไม่ต้องตั้งค่าเซิร์ฟเวอร์ใด ๆ

### โหมด B — ผ่าน Apps Script (ทางเลือก)
สำหรับ cache ฝั่งเซิร์ฟเวอร์ กันเรียกถี่เกินโควตา: วางโค้ด `apps-script/Code.gs` ใน Extensions > Apps Script ของชีต แล้ว Deploy เป็น Web app (Anyone) นำ URL `/exec` มาใส่ `SHEET_URL` (ถ้าใส่ทั้งคู่ ระบบจะใช้โหมด B)

## การติดตั้งชีตครั้งแรก

1. เปิด Google Sheets ของสาขา → **Extensions > Apps Script**
2. วางโค้ดจาก `apps-script/Code.gs` ทับทั้งหมด → บันทึก
3. รันฟังก์ชัน `setupSheets` (ครั้งแรกขอสิทธิ์ — อนุญาตได้เลย)
   - ได้แท็บ **Schedule / Exams / ExamImages / Posts / Config** พร้อมหัวตาราง dropdown และแถวตัวอย่างสองสามแถวเพื่อดูรูปแบบ — **ลบแถวตัวอย่างได้เลย** หน้าเว็บจะว่างตามจริงจนกว่าจะใส่ข้อมูลจริง
4. กลับมาที่หน้าชีต จะมีเมนู **⚙️ RTPI** ให้ล้าง cache / ตั้งค่าชีตซ้ำได้

## การใช้งานประจำวัน (สำหรับผู้ดูแลข้อมูล)

| ต้องการ | ทำอย่างไร |
|---|---|
| ประกาศตารางสอบ | เพิ่มแถวในแท็บ **Exams** |
| **สาขาส่งตารางสอบมาเป็นรูป** | อัปโหลดรูปขึ้น Google Drive → คลิกขวา **แชร์ → ทุกคนที่มีลิงก์ (ผู้ดู)** → ก็อปลิงก์ → ใส่ในแท็บ **ExamImages** (เว็บแปลงลิงก์ Drive ให้แสดงเอง คลิกที่รูปเพื่อซูมดูเต็มจอ) |
| แก้ตารางสอน | แก้/เพิ่มแถวในแท็บ **Schedule** |
| โพสต์กิจกรรม/ข่าว | เพิ่มแถวในแท็บ **Posts** (หมวดเลือกจาก dropdown ได้) |
| แบนเนอร์ประกาศวิ่ง / ปีการศึกษา / ลิงก์ไลน์ | แก้ค่าในแท็บ **Config** |

หมายเหตุ: คอลัมน์วันที่กรอกวันที่จริง (เช่น 21/9/2026) ได้เลย ระบบจัดรูปแบบให้เอง

## ฟีเจอร์เว็บ

- ค้นหา + กรองตารางสอบ/ตารางสอน (ปี ภาคเรียน กลุ่ม ประเภท) พร้อมนับถอยหลังวันสอบ
- หน้าค้นหารวม (`search.html`) ไฮไลต์คำค้น
- ตารางสอน 2 มุมมอง: รายวัน / ตารางรายสัปดาห์
- แกลเลอรีรูปตารางสอบ + Lightbox ซูม
- โหมดมืด/สว่าง (จำค่าไว้), ปุ่มพิมพ์ตาราง, ปุ่มกลับขึ้นด้านบน
- อัปเดตอัตโนมัติทุก 60 วินาที + เมื่อกลับมาที่แท็บ
- ฟอนต์ทางการ: หัวข้อ Noto Serif Thai / เนื้อหา Sarabun
