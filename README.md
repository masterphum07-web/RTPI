# RTPI — เว็บไซต์รวมตารางสอบ/ตารางสอน สาขาวิชารังสีเทคนิค วทก.

เว็บสำหรับนักศึกษาสาขาวิชารังสีเทคนิค วิทยาลัยเทคโนโลยีทางการแพทย์และสาธารณสุข กาญจนาภิเษก (วทก.)
ใช้ค้นหา **ตารางสอบ ตารางสอน และติดตามกิจกรรม/ข่าวสารของสาขา** — ข้อมูลอยู่บน Google Sheets ของสาขา และมี**ระบบผู้ดูแล** สำหรับอัปโหลดรูปตาราสอบ/ตารางสอนได้โดยตรงจากหน้าเว็บ

## เปิดเว็บ

- เว็บไซต์: https://masterphum07-web.github.io/RTPI/
- **ระบบผู้ดูแล**: https://masterphum07-web.github.io/RTPI/admin.html (รหัสผ่านเริ่มต้น `12345` — เปลี่ยนได้ที่ `ADMIN_PASS` ใน Code.gs)

## โครงสร้างโปรเจค

```
RTPI/
├── index.html          หน้าแรก (สถิติ, สอบใกล้ถึง, ประกาศล่าสุด)
├── exams.html          ตารางสอบ + แท็บรูปประกาศตารางสอบ (ซูมได้)
├── schedule.html       ตารางสอน (รายวัน / ตารางรายสัปดาห์ / รูปตารางสอน)
├── activities.html     ฟีดกิจกรรม/ประกาศ/ทุน/ฝึกงาน
├── search.html         ค้นหารวมทุกอย่างจากที่เดียว
├── admin.html          🔐 ระบบผู้ดูแล (อัปโหลดรูป/ลบรูป/เพิ่มข้อมูลตาราง)
├── css/style.css       ธีมทางการ (น้ำเงิน–ทอง) + โหมดมืด
├── js/config.js        ⚙️ ตั้งค่า SHEET_ID / SCRIPT_URL
├── js/data.js          ดึงข้อมูลจากชีต (gviz) + auto-refresh
├── js/ui.js            Header/Footer/สถานะ/โหมดมืด/Lightbox
├── icons/              โลโก้วิทยาลัย + โลโก้สาขา
├── apps-script/Code.gs สคริปต์ชีต + API แอดมิน
└── manifest.webmanifest ติดตั้งเป็นแอปบนมือถือได้ (PWA)
```

## การเชื่อมต่อข้อมูล

- **อ่านข้อมูล**: ดึงจาก Google Sheets โดยตรง (`SHEET_ID` ใน `js/config.js` — ชีตต้องแชร่ "ทุกคนที่มีลิงก์ – ผู้ดู") อ่านแท็บ `Schedule`, `Exams`, `Posts`, `Images`, `Config`
- **เขียนข้อมูล** (หน้าแอดมิน): ส่งไปที่ Apps Script Web app (`SCRIPT_URL` ใน `js/config.js`)

## ★ การอัปเกรด Apps Script (ทำเมื่อวาง Code.gs รุ่นใหม่)

1. เปิด Google Sheets ของสาขา → **Extensions > Apps Script**
2. วางโค้ดจาก `apps-script/Code.gs` ทับของเดิมทั้งหมด → บันทึก
3. รันฟังก์ชัน `setupSheets` — ระบบจะสร้างแท็บ **Images** + ย้ายรูปจากแท็บ ExamImages เดิม (ถ้ามี) + แก้ชื่อวิทยาลัยใน Config ให้อัตโนมัติ
4. **Deploy > Manage deployments > ✏️ Edit > Version: New version > Deploy**
   ← สำคัญ: ใช้วิธีนี้เพื่อให้ URL เท่าเดิม ไม่ต้องแก้ config.js ฝั่งเว็บ

ครั้งแรก (ยังไม่เคยวางโค้ดเลย): ทำข้อ 2-3 แล้ว **Deploy > New deployment > Web app** (Execute as: Me / Who has access: Anyone) แล้วนำ URL `/exec` ใส่ `SCRIPT_URL` ใน `js/config.js`

## การใช้งานประจำวัน

| ต้องการ | ทำอย่างไร |
|---|---|
| **อัปโหลดรูปตารางสอบ/ตารางสอน** | เข้า `admin.html` → ล็อกอิน → เลือกไฟล์ + หมวดหมู่ → อัปโหลด (รูปเก็บใน Google Drive โฟลเดอร์ RTPI-Uploads และขึ้นเว็บทันที) |
| ลบรูป | แท็บ "จัดการรูปทั้งหมด" ในหน้าแอดมิน |
| เพิ่มข้อมูลตารางแบบพิมพ์/วาง | แท็บ "เพิ่มข้อมูลตาราง" ในหน้าแอดมิน — วางข้อมูลคั่นช่องด้วย Tab หรือ \| |
| แก้ข้อมูลจำนวนมาก | แก้ตรง ๆ ใน Google Sheets (แท็บ Schedule / Exams / Posts / Images / Config) |
| แบนเนอร์ประกาศวิ่ง / ปีการศึกษา / ลิงก์ไลน์ | แก้ค่าในแท็บ **Config** |

หมายเหตุ: ลิงก์รูปในแท็บ Images รองรับลิงก์แชร์ Google Drive (เว็บแปลงให้อัตโนมัติ) · คอลัมน์วันที่กรอก 21/9/2026 ได้เลย ระบบจัดรูปแบบให้

## ฟีเจอร์เว็บ

- ค้นหา + กรองตารางสอบ/ตารางสอน + นับถอยหลังวันสอบ + หน้าค้นหารวมพร้อมไฮไลต์คำค้น
- ตารางสอน 3 มุมมอง: รายวัน / ตารางรายสัปดาห์ / รูปตารางสอน
- แกลเลอรีรูปตารางสอบ + Lightbox ซูม
- ระบบผู้ดูแล: อัปโหลด/ลบรูป, เพิ่มแถวข้อมูล (รหัสผ่านอยู่ที่ ADMIN_PASS ใน Code.gs)
- โหมดมืด/สว่าง, ปุ่มพิมพ์ตาราง, ปุ่มกลับขึ้นด้านบน, PWA ติดตั้งบนมือถือ
- อัปเดตอัตโนมัติทุก 60 วินาที + เมื่อกลับมาที่แท็บ
- ฟอนต์ทางการ: หัวข้อ Noto Serif Thai / เนื้อหา Sarabun + โลโก้วิทยาลัยและสาขา

## หมายเหตุด้านความปลอดภัย

ระบบรหัสผ่านแอดมินเป็นแบบพื้นฐาน (เหมาะกับการใช้ภายในสาขา) — ทุกคนที่รู้รหัสสามารถอัปโหลด/แก้ไขข้อมูลได้ เมื่อย้ายหลังบ้านเป็น .NET (ASP.NET Core + ฐานข้อมูลจริง) ควรเปลี่ยนเป็นระบบล็อกอินแบบมีบัญชีผู้ใช้
